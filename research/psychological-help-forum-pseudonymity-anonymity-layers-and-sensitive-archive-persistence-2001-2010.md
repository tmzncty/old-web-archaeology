> Scope：严格服务于 `old-web-archaeology` 的约 1995–2015 中文互联网主范围。
>
> 交叉生活史见：
> https://github.com/tmzncty/how-people-lived/blob/main/sources/psychological-hotlines-anonymous-forums-help-seeking-addressability-and-low-identity-disclosure-china-1987-2025.zh-CN.md
>
> 本文不复原、转贴或批量采集普通人的历史心理求助正文。研究对象是：**当年的入口、账户要求、化名/匿名承诺、公开性、回复状态、跨渠道转介和归档边界。**

## 0. 去重：为什么不是既有“健康门户 / 患者论坛”状态缺口的重复

仓库已有：

- `HEALTH_PORTAL_QA_PATIENT_FORUM_DOCTOR_PROFILE_CONSULTATION_AND_OFFLINE_CARE_STATE_GAPS_2000_2015.md`

该文件已经证明：

```text
公开健康问答
!= 正式诊疗

医生主页存在
!= 医生真正接诊

论坛经验
!= 临床证据
```

本 note 不再重复这些结论。

本轮新增的问题是：

> **当一个服务明确鼓励用户以“不署名”、昵称、账号或其他低身份方式谈论极敏感心理问题时，Web 的账户、公开页面、搜索引擎和 archive 会不会把“互动时的低暴露”变成多年后的持久可检索文本？**

这是一个身份 / 受众 / 保存层问题，而不只是医疗事务状态问题。

## 1. M1 状态

按 `ROADMAP.md` 与 `docs/METHOD.md`，一个 M1 完整案例至少需要：

- 身份确认；
- ≥2 历史时点；
- 尽可能 ≥2 evidence family；
- 资源缺失清单；
- 浏览器 / 编码 / 插件假设；
- “已证实 / 高概率 / 不知道”；
- 实际检查过的历史 capture。

本轮取得：

- 2001 校园心理站点的同期媒体功能描述；
- 2003 北大 SARS 心理援助 BBS 的同期 URL locator；
- 2005 青少年心理辅导论坛“无需署名 + 注册/登录 + 发帖 + 定时答复”的同期流程描述；
- 2006–2010 电话热线作为同一求助生态中的非 Web 对照；
- 明确的 privacy / archive research contract。

本轮**没有**取得：

- 已实际打开并核验的 2001–2010 historical memento；
- 原始 HTTP / DOM / charset；
- 注册字段；
- cookie/session 逻辑；
- 搜索引擎 robots/meta 状态；
- 删除按钮及删除后行为；
- 同一论坛 ≥2 个历史时点；
- 当年平台日志政策。

因此：

> **M1 verified historical Chinese psychological-help forum capture: NOT ACHIEVED IN THIS SLICE.**

这不等于“Wayback 没保存”。只能说本轮没有获得满足仓库最低证据合同的已核验历史 capture。

## 2. 研究单位：不要把“匿名心理咨询网站”压成一个对象

### 2.1 Service / institution

提供心理支持的机构、学校、媒体或专业组织。

### 2.2 Entry page

介绍热线、论坛、聊天室、咨询时段或帮助规则的页面。

### 2.3 Platform account

注册后形成的账号。

需要区分：

- 是否必须注册；
- 是否要求邮箱 / 手机；
- 是否要求真实姓名；
- 对其他用户显示什么；
- 平台内部能看到什么。

### 2.4 Pseudonym

用户对公众显示的昵称。

```text
pseudonym
!= no account
!= no platform logs
!= no cross-site identity linkage
```

### 2.5 Anonymous submission

界面可能允许不填写姓名，或允许匿名 / 游客方式提交。

必须记录“匿名”是平台营销语言、界面字段状态，还是技术上已经验证的不可识别状态。

### 2.6 Question / disclosure text

用户实际写下的困扰正文。

它是极敏感历史材料。研究平台结构时原则上不需要复制正文。

### 2.7 Public thread

帖子可能对所有访客公开，也可能只对注册用户可见。

### 2.8 Counselor response

咨询人员、专家或版主留下的回复。

```text
response visible
!= user read response
!= user accepted suggestion
!= referral completed
```

### 2.9 Hotline call

非 Web 的同步求助事务。

它通常比公开论坛留下更少可见文本，但运营方仍可能保有内部记录。

### 2.10 Referral

把用户从热线 / 论坛导向学校咨询室、医院、其他热线或线下服务的动作。

### 2.11 Archive capture

Web archive、搜索缓存、转载页或现代遗留页面保存的一份表示。

必须和当时互动场景分开。

## 3. 2001：校园网络心理站点已经把“电话热线”扩展成多种 Web 互动形态

2001-12-21《中国教育报》介绍国防科技大学“心之桥”。材料记载该活动从 1997 年的热线等形式发展，到 2000-11-08 进入校园网络，站点有“知心聊天室”“心理辅导室”“心理沙龙”“心情绿岛”等栏目，并在固定时段邀请专家与学生在线交流。

来源：

- 中国教育和科研计算机网转载《中国教育报》，2001-12-21：
  https://www.edu.cn/gao_jiao_news_367/20060323/t20060323_21599.shtml

证据等级：**B（同期教育媒体）**。

可确认：

- 心理支持服务已经出现校园网络入口；
- 同步聊天室、内容栏目和心理辅导等不同对象并存；
- 电话与网络并非简单替代。

不可确认：

- 原站 host / URL；
- 页面是否公网开放；
- 用户是否需要统一身份认证；
- 聊天记录是否保存；
- 咨询内容是否公开；
- HTML / charset / browser requirements。

而且这是网络基础设施较好的高校环境，不能推成当时普通家庭中文互联网的默认体验。

## 4. 2003：SARS 心理援助出现明确的 BBS locator，但 locator 仍不是 capture

2003-05-08《北京晚报》报道，北京大学相关机构和中国心理学会在 SARS 时期同时提供心理援助热线，并给出专题论坛地址：

```text
www.psy.pku.edu.cn/bbs
```

来源：

- 新浪转载《北京晚报》，2003-05-08：
  https://news.sina.com.cn/o/2003-05-08/1716108366s.shtml

证据等级：**B（同期新闻）**。

这能证明：

- 当时媒体向公众传播过该 URL；
- BBS 被当成心理援助渠道的一部分。

不能证明：

- URL 在哪一天可访问；
- forum software；
- 是否要求账号；
- 是否允许游客发帖；
- 帖子是否公开索引；
- 具体帖子是否真的得到回复。

按本仓 `METHOD.md`：

> **historical URL locator != verified historical capture**。

因此本轮把这个地址登记为重要 locator，但不把它冒充 M1 artifact。

## 5. 2005：最关键的矛盾——“不必署名”与“注册 / 登录”同时存在

2005-11-21 的同期报道介绍“中国青年网青少年心理辅导论坛”。报道强调，年轻人可以“不必打电话，不必署名”，直接到网页留下问题；但操作路径同时写明，需要进入论坛，完成注册 / 登录，再把问题发到论坛，由专业心理咨询人员在规定时段回复。

来源：

- 国际在线 / 新浪，2005-11-21：
  https://news.sina.com.cn/c/2005-11-21/17377499373s.shtml

证据等级：**B（同期新闻）**。

这是一个非常有价值的接口证据，因为它直接证明：

```text
NO_SIGNATURE
AND
ACCOUNT_SESSION
```

可以同时成立。

所以今天研究旧网时不能把“匿名”设成一个 boolean。

## 6. 新机制一：`anonymity-layer split / 匿名层分裂`

一个历史求助服务至少可能有以下身份层：

| 层 | 应记录的问题 |
|---|---|
| 现实姓名 | 是否必须填写真实姓名？ |
| 注册身份 | 是否需要账号、邮箱、手机或校园账号？ |
| 公开显示 | 访客看到真实姓名、昵称、匿名标签还是游客？ |
| 平台内部 | 平台是否可能拥有 IP、登录记录、注册资料？ |
| 对咨询者 | 咨询师是否能看到更多身份信息？ |
| 搜索引擎 | 页面是否允许抓取、是否能按昵称/关键词找到？ |
| archive | 历史页面是否可能被长期保存？ |
| 跨数据关联 | 昵称、邮箱片段、个人细节以后是否可能和其他站点对应？ |

因此建议 evidence schema 使用独立字段，而不是一个 `anonymous: true/false`：

```yaml
real_name_required: unknown
account_required: true
public_name_mode: pseudonym_or_unsigned
contact_required: unknown
public_visibility: unknown
search_indexable: unknown
platform_log_retention: unknown
delete_control: unknown
archive_capture_possible: unknown
```

“unknown”必须允许大量存在。

## 7. 新机制二：`interactional anonymity != archival anonymity`

用户在 2005 年发帖时可能真实感受到：

> 我没有当面对父母、老师、同学说，也没有在帖子上签真实姓名。

这种**互动时低暴露**是真实的社会体验。

但 twenty years later 的研究者面对的是另一套基础设施：

- 全文搜索；
- 搜索引擎缓存；
- Web archive；
- 转载聚合；
- 昵称跨站检索；
- 数据集和大模型检索。

因此：

```text
anonymous-enough-for-2005-interaction
!=
anonymous-under-2026-retrieval
```

本文把它定义为：

**`interactional anonymity != archival anonymity / 互动匿名不等于档案匿名`**。

这不是说当年平台“欺骗”用户。很多风险来自后来搜索、归档和关联能力扩大，而不是当年服务可以完全预见的结果。

## 8. 新机制三：`audience-boundary drift / 受众边界漂移`

心理求助帖尤其容易发生上下文改变。

用户当时设想的受众可能只是：

```text
某论坛的咨询师
+ 当时少量站友
```

但保存以后，潜在受众可能变成：

```text
搜索引擎用户
+ 后来的同事 / 家人 / 伴侣
+ 历史研究者
+ 数据采集器
+ 自动化检索系统
```

这构成 **`audience-boundary drift / 受众边界漂移`**。

网页本身没有改一个字，它的社会可见性却可能彻底改变。

所以：

**`text preservation success != contextual privacy preservation`**。

## 9. 电话热线与论坛不是同一种保存对象

2006 年的同期热线报道记录一名未成年人因为不愿向同学、父母表达而打电话求助。

来源：

- 2006-03-13 同期报道：
  https://news.sina.com.cn/o/2006-03-13/11148430761s.shtml

本仓不保存更多未成年人个人细节。

从考古角度，电话和论坛形成鲜明对照：

### 电话

通常可公开保存的是：

- 号码；
- 服务时间；
- 主办机构；
- 服务说明；
- 汇总统计；
- 媒体选取的个案片段。

真实对话很可能完全不进入 Web archive。

### 论坛

可能留下：

- 入口页；
- 帮助页；
- 注册页；
- 帖子列表；
- 用户问题；
- 咨询师回复；
- 搜索结果。

因此论坛在历史可见性上可能**比当年的求助者预期更持久**。

这不意味着论坛更差，而意味着研究者必须把保存能力也作为服务社会后果的一部分。

## 10. 2008：公开调查与个人求助材料证明“页面可见”并不是完整求助状态

2008-11-13《中国青年报》报道一项网络调查和若干校园个案。报道中的学生有人参加团体辅导，有学生工作者自己进入心理咨询，并明确谈到“说出来”和获得回应的作用。

来源：

- 新浪教育转载《中国青年报》，2008-11-13：
  https://edu.sina.com.cn/l/2008-11-13/1027156662.shtml

证据等级：**B / T1**。

它提示旧网研究不能停在：

```text
心理咨询网页存在
```

实际求助链至少应拆成：

```text
person has distress
→ discovers entry point
→ chooses phone / forum / chat / offline
→ connects or posts
→ service accepts / moderates
→ counselor sees
→ counselor responds
→ user hears / reads response
→ optional follow-up
→ optional referral
→ optional formal care
```

archive 最容易保存的是中间少数公开页面，而不是链条两端。

## 11. `help-channel state model`

建议后续案例使用以下状态，而不是 `consulted: true`：

```text
ENTRY_ADVERTISED
ENTRY_REACHABLE
ACCOUNT_CREATED          # if required
QUESTION_DRAFTED
QUESTION_SUBMITTED
QUESTION_ACCEPTED
QUESTION_PUBLIC           # only if applicable
COUNSELOR_ASSIGNED        # often unknown
RESPONSE_WRITTEN
RESPONSE_VISIBLE
USER_READ_RESPONSE        # usually private/unknown
FOLLOWUP_OCCURRED         # often off-platform/unknown
REFERRAL_OFFERED
REFERRAL_ACCEPTED         # usually unknown
OFFLINE_CARE_OCCURRED     # another evidence domain
```

这与普通健康问答 state chain 相邻，但这里额外需要：

```text
IDENTITY_DISCLOSED_TO_PUBLIC
IDENTITY_DISCLOSED_TO_PLATFORM
IDENTITY_DISCLOSED_TO_COUNSELOR
```

分别记录。

## 13. 归档伦理：这里的“缺失”有时比“复原”更应该被尊重

`docs/METHOD.md` 已规定：研究普通个人页面和已删除敏感内容时实行研究必要最小化。

心理求助材料属于尤其高敏感领域。

因此本专题额外使用以下合同：

### 可以优先保存

- 服务公告；
- 主页 / 帮助页；
- 注册要求；
- 页面字段名；
- 公开说明的咨询时段；
- 主办单位；
- forum software / charset / browser evidence；
- 帖子数量等聚合结构（若可验证）；
- 已公开的专业人员说明。

### 不应为了“案例完整”而批量重发

- 普通用户心理困扰全文；
- 未成年人求助正文；
- 联系方式；
- 可跨站定位身份的昵称组合；
- 已删除但 archive 中仍可恢复的敏感帖子；
- 诊断、自伤、家庭冲突等不必要细节。

### 推荐的 artifact 展示方式

如果未来取得 forum capture，优先展示：

- 页面骨架；
- 输入字段；
- 账户 / 匿名选项；
- 版块结构；
- pagination；
- 时间戳格式；
- 咨询师 badge；
- 状态提示。

对用户正文使用模糊化、占位符或 synthetic fixture，而不是复制真实内容。

## 14. 海外边界：Usenet `alt.support.depression` 提醒我们“公开网络互助”早于 Web

Daniel Huang 对 1990–1999 年 `alt.support.depression` 的历史研究显示，Usenet 已经形成规模很大的抑郁症支持社群；一份保存的历史 FAQ 文本还专门解释如何匿名发帖。

来源：

- https://pubmed.ncbi.nlm.nih.gov/35641132/
- https://www.biopsychiatry.com/alt-depression/faq1-5.html
- https://www.biopsychiatry.com/alt-depression/faq5-5.html

这部分只作为 HPL 跨国机制比较，不扩大 OWA 的主 scope。

它对 OWA 的方法启发是：

```text
support community
可以在 Web 之前存在

publicly posted
可以和 pseudonymous / anonymous 同时存在
```

因此不能把“公开”“匿名”“私密”当成同一个维度。

## 15. 已证实 / 高概率 / 不知道

### 已证实

- 2001 同期教育媒体描述某高校心理服务已经进入校园网络，并包含聊天室 / 辅导 / 沙龙等栏目；
- 2003 同期新闻给出北大 SARS 心理援助 BBS 的 URL locator；
- 2005 同期新闻明确同时写出“不必署名”和“注册 / 登录后论坛发帖”；
- 当时电话热线和 Web / BBS 可以作为并行渠道存在。

### 高概率但尚未 artifact 验证

- 2005 论坛拥有持续 account/session state；
- 帖子可能形成固定 thread page；
- 部分问题和回复可能公开可见。

以上必须等 historical capture 才能提升。

### 不知道

- 注册字段；
- 是否收集邮箱 / 手机；
- 平台日志保存多久；
- 是否允许真正游客匿名；
- 搜索引擎是否能抓取；
- robots / meta 设置；
- 删除 / 编辑机制；
- 普通用户是否知道 archive 风险；
- 原始页面的 GB2312 / GBK / UTF-8；
- 浏览器要求；
- 多少求助真正得到回答；
- 多少人后来进入正式咨询 / 医疗。

## 16. 后见之明风险

### 16.1 不用今天的实名制经验倒推 2005

必须从当年页面字段和规则验证账户身份强度。

### 16.2 不用今天的搜索可见性倒推当年预期受众

页面现在能被搜索，不代表 2005 用户预期它会被 20 年后的搜索系统找到。

### 16.3 不把“论坛发帖”写成“接受心理治疗”

它可能只是一次异步倾诉或问答。

### 16.4 不把“匿名”写成绝对技术不可识别

历史材料最多证明当时公开界面和用户体验中的低署名 / 化名机制。

### 16.5 不因 archive 能看见而默认适合再发布

`public then` 不自动等于 `ethical to amplify now`。

## 17. 下一步若继续，应优先做什么

不是再写一篇“互联网让心理咨询更方便”。

优先级应是：

1. 找到并**实际打开** `www.psy.pku.edu.cn/bbs` 2003 前后的 historical memento；
2. 定位 2005 青少年心理辅导论坛原 host / URL，并验证至少两个历史时点；
3. 只对帮助页、注册页、论坛结构做 capture evidence，不主动搜普通用户敏感正文；
4. 记录 charset、browser、表单字段、cookie/login wall、robots/meta、删除选项；
5. 为 M1 选择一个隐私风险较低的社区案例时，优先考虑非敏感论坛；心理求助案例更适合作为**方法边界 / 伦理案例**，而不是展示型完整复原案例。

最后一点尤其重要：

> old-Web archaeology 的成熟，不应该以“能把别人当年最私密的话重新挖出来”为成就。
>
> 对这类站点，能够可靠说明**当时如何进入、以什么身份说话、谁能看见、系统如何回应，以及今天为什么不应该重新放大正文**，本身就是完整的研究成果。
