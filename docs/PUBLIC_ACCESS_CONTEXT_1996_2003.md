# 1996—2003 公共上网环境：同一个网页，在家里和网吧不是同一种体验

本文件补充：

- `docs/PREHISTORY_BOUNDARY.md`；
- `docs/DIALUP_ACCESS_CONTEXT_1995_1998.md`。

主研究对象仍然是约 1995—2015 年中文互联网。

这里不写完整“网吧史”，而是给早期网页、BBS、聊天室、OICQ/QQ、个人主页等案例补一个经常被忽略的访问环境：

> **用户并不一定拥有正在使用的电脑、线路、浏览器或本地硬盘。**

这会直接影响我们怎样解释旧网页、联系方式、账号、软件下载、Cookie、本地文件和线下身份。

---

## 1. 为什么旧网案例必须增加 `public-access` 这一层

家庭拨号的典型栈是：

```text
家庭/宿舍电脑
+ modem
+ 固定电话线
+ ISP 账号
+ 用户自己的浏览器和本地文件
```

公共上网场所则可能是：

```text
经营者拥有电脑和线路
+ 多人轮流使用同一终端
+ 按小时计费
+ 统一安装浏览器/输入法/聊天软件
+ 本地文件可能被清除、共享或不可长期保存
+ 用户通过服务器端账号保持身份连续
```

所以“这个网站在 2000 年可以访问”仍然不足以还原具体体验。

必须继续问：

> **是在谁的机器上访问？**

## 2. 1996—1997：北京已经出现面向付费顾客的 Internet 终端

北京日报后来整理自身 1996—1997 年报道时记载：

- 1996 年 11 月，北京“实华开网络咖啡屋”开业；
- 1997 年 1 月探访时，店内有 11 台奔腾电脑；
- 记者观察到大学生发电子邮件、公司职员查资料、年轻人聊天、外国人玩网络游戏；
- 1997 年初北京已有近 10 家类似场所，主要集中于海淀、中关村一带。

来源：

- 人民网转载《北京日报》历史报道整理，2019；原文指向 1996-11-23 与 1997-01-24 报道：<https://media.people.com.cn/n1/2019/1017/c40606-31404334.html>

### 证据等级

- 原始事件发生于 1996—1997；
- 当前可直接访问的是报社 2019 年回顾性重刊/整理；
- 因此本文把它作为 **B/C 边界材料：后来机构整理，明确引用自身同时代报道**；
- 不据此解决“中国第一家网吧”的绝对优先权争议。

旧网考古真正需要的结论更窄：

> **1996—1997 年北京已经存在让没有自有 Internet 终端的人按场所进入网络的商业入口。**

## 3. 1999 CNNIC：早期网民仍以单位/家庭为主，但网吧已经进入统计表

CNNIC 第四次调查，数据截止 1999-06-30。

宏观统计：

- 上网用户约 400 万；
- 上网计算机 146 万台；
- 其中拨号上网计算机 121 万台。

其网上联机问卷有效样本 52,549 份。

“上网的主要地点”：

| 地点 | 比例 |
|---|---:|
| 单位 | 47% |
| 家中 | 44% |
| 网吧 | 4% |
| 其它 | 5% |

来源：

- CNNIC，《第四次中国互联网络发展状况调查统计报告》，1999-07：<https://www.cnnic.cn/NMediaFile/old_attach/P020120612485127164902.pdf>

### 重要限制

这是网上自愿问卷，不是“全国所有人”的随机抽样。

它可以说明早期网民样本里的访问地点结构，不能把 4% 直接解释为全国人口网吧使用率。

## 4. 2000—2002：公共接入已经成为旧网受众环境的重要部分

国务院办公厅 2001 年文件回顾 2000 年底状况时称：

- 全国网民约 2250 万；
- 其中 20.5% 通过“网吧”等互联网上网服务营业场所上网；
- 一些大城市已有近千家此类营业场所。

来源：

- 国办发〔2001〕21号，上海市政府转载：<https://www.shanghai.gov.cn/nw4052/20200813/0001-4052_50.html>

CNNIC 2001 年 7 月报告同期转刊记录的上网地点包括：

- 家中 61.0%；
- 单位 45.1%；
- 学校 18.3%；
- 网吧 15.2%。

来源：

- CNNIC 报告同期转刊，新浪科技，2001-07-17：<https://tech.sina.com.cn/i/c/2001-07-17/76286.shtml>

2002 年 7 月第十次 CNNIC 调查：

- 家中 62.1%；
- 单位 43.3%；
- 学校 21.8%；
- 网吧/咖啡厅 17.3%；
- 公共图书馆 0.7%；
- 移动且地点不固定 0.9%。

来源：

- CCTV 转刊 CNNIC 第十次报告，2002-07-22：<https://news.cctv.com/news/china/20020722/244.html>

2002 年底第十一次 CNNIC 调查又记录：

- 网吧、网校、网络咖啡厅：19.4%。

来源：

- CNNIC 第十一次报告同期转刊，新浪科技，2003-01-16：<https://tech.sina.com.cn/i/c/2003-01-16/1634161525.shtml>

### 不要把这些点画成一条精确趋势线

20.5%、15.2%、17.3%、19.4% 来自不同文件、时点、问题和调查设计。

可安全使用的结论是：

> **2000—2002 年，公共商业上网已经是相当大一部分早期网民真实使用过的接入环境。**

不能据此声称某一年全国严格占比就是某个精确百分数。

## 5. 2002：网吧从“技术入口”变成有独立制度边界的场所

2002 年文化部加强互联网上网服务营业场所管理。

同期新华社报道的规则包括：

- 消费者入场登记；
- 场内巡查；
- 学校周边距离要求；
- 未成年人进入时段和时长限制。

来源：

- 新华社稿，中国教育和科研计算机网转载，2002-05-17：<https://www.edu.cn/zhong_guo_jiao_yu/ji_chu/ji_jiao_news/200603/t20060323_26932.shtml>

《人民日报》2002 年 8 月调查报道援引文化部门数据称：

- 北京有 2400 多家网吧，证件齐全约 200 家；
- 全国至少约 20 万家网吧；
- 很大比例处于无证或证照不全状态。

来源：

- 《人民日报》，2002-08-22，第 11 版，《透视“黑网吧”泛滥》：<https://cn.govopendata.com/renminribao/2002/8/22/11/>

这对旧网考古的直接意义是：

> 到 2002 年，公共终端不再只是“另一种电脑”，而是一个有营业许可、入场条件、身份登记、时间限制和场所管理的网络环境。

## 6. 公共终端会改变哪些网页证据的解释？

### 6.1 浏览器首页未必是用户自己选的

如果一台网吧电脑：

- 由管理员统一安装；
- 统一设置首页；
- 每天恢复系统；
- 预装门户、聊天软件或游戏；

那么“某用户总是从某门户开始上网”不能只用个人偏好解释。

需要区分：

```text
用户主动选择
vs
终端默认配置
vs
网吧经营者配置
vs
ISP/浏览器默认
```

### 6.2 Cookie、历史记录和收藏夹可能不是私人长期档案

家庭电脑上的：

- 浏览历史；
- Cookie；
- 收藏夹；
- 下载目录；
- 聊天记录；

可能长期留在同一台机器。

公共终端则可能：

- 被下一位顾客看到；
- 被管理员清理；
- 重启后恢复；
- 根本不允许长期保存。

所以研究“早期用户怎样保存网页或回到同一网站”时，终端所有权非常关键。

### 6.3 服务器端账号比本地机器更重要

Email、BBS ID、OICQ/QQ、聊天室昵称等账号可以从另一台终端重新登录。

因此公共接入环境会强化：

> **账号身份与物理机器分离。**

这是一条值得在旧 SNS、论坛与即时通信案例里继续追踪的 lineage。

### 6.4 下载并不等于“带回家”

一个网页提供：

- ZIP；
- MP3；
- 图片；
- 软件；
- 文档；

并不代表公共终端用户能够长期保留。

还要问：

- 能否使用软盘、U盘、刻录盘；
- 是否允许下载；
- 本地磁盘是否重启清除；
- 文件是否只能临时使用；
- 是否通过 Email/网盘/FTP 再转移。

网页“可下载”与用户“可拥有文件”不是同一件事。

## 7. 旧网页上的联系方式，需要放回“公共机器”场景

一个 1999—2002 年页面如果同时留下：

- 电话；
- BP 机；
- Email；
- OICQ/QQ；
- BBS ID；
- 邮政地址；

那么这些渠道对应不同的可达性。

对公共上网用户而言，Email / BBS / 即时通信账号有一个特别性质：

> **只要能找到下一台联网终端，账号可以继续跟着人。**

这使网络身份可能比：

- 家庭电话线；
- 当前宿舍；
- 当前工作单位；
- 当前电脑

更可携带。

但此处目前主要是机制判断。

未来仍需同时代用户材料证明具体人群怎样跨网吧、跨学校、跨城市保持账号连续性。

## 8. 海外最小对照：伦敦 Internet cafe 也承担“无需家庭 Internet 即可上线”的功能

1994 年《卫报》报道伦敦 Cyberia 时，已经描述：

- 至少 6 台终端；
- Mosaic 浏览器；
- 面向公众的 Internet access；
- 预计按小时收费。

来源：

- *The Guardian*, 1994-09-07：<https://www.theguardian.com/technology/1994/sep/08/internet>

1999 年伦敦 easyEverything 开业时：

- 有 400 多台终端；
- 24 小时营业；
- 初期约 1 英镑/小时；
- 同期报道把它与更高的家庭高峰连接成本比较。

来源：

- *The Guardian*, 1999-06-17：<https://www.theguardian.com/technology/1999/jun/17/onlinesupplement19>

这个海外对照在本仓只承担一个方法提醒：

> **公共 Internet 接入是全球早期网络社会常见的一种中间层，但它在各地的重要程度由家庭电脑、电话资费、ISP、城市密度和公共场所经济共同决定。**

本仓不在此展开英国网吧史。

## 9. 早期 case 建议新增的 public-access 字段

对约 1996—2003 的中文网站、BBS、聊天室、即时通信与下载站案例，可在证据允许时增加：

| 字段 | 研究问题 |
|---|---|
| terminal_owner | household / school / employer / cafe / library / unknown |
| public_access | yes / no / plausible / unknown |
| session_billing | 是否按小时/时段付费 |
| terminal_count | 场所规模（若有同时代证据） |
| browser_control | 用户自选 / 管理员统一 / unknown |
| homepage_control | 用户 / ISP / 网吧 / 浏览器默认 / unknown |
| local_storage | persistent / shared / cleared / unknown |
| install_rights | 能否安装软件 |
| removable_media | floppy / CD-R / USB / none / unknown |
| account_portability | Email/BBS/IM 等是否可跨终端登录 |
| identity_requirement | 是否需要现实身份证件登记 |
| age_time_rules | 是否存在年龄/时段限制 |
| access_hours | 营业时间 / 校园机房时间 / unknown |
| offline_bridge | 电话、BP机、传真、线下会面如何继续网络互动 |

不是每个 case 都必须填满。

缺失时写 `unknown`。

## 10. 对 archived page 的三个新警告

### 警告一：页面保存下来，不代表用户拥有自己的机器

archive 只保存页面侧证据。

它通常看不见访问者是在：

- 家；
- 单位；
- 学校；
- 网吧；
- 图书馆。

不要把现代私人设备经验自动投射到访问者身上。

### 警告二：网页的“默认入口”可能是场所配置结果

门户首页、收藏夹、桌面快捷方式、预装客户端可能由网吧管理员决定。

这会影响流量和网站发现路径。

### 警告三：网络身份连续，不等于本地数据连续

用户可能连续多年使用同一个 QQ/BBS/Email 身份，却每次在不同的公共终端登录。

所以：

```text
identity continuity
!=
device continuity
!=
local-file continuity
```

这三个维度必须分开。

## 11. 当前可证实 / 可推断 / 尚未知

### 已证实

- 1996—1997 年北京已经有面向付费顾客的 Internet 公共终端场所；
- 1999 CNNIC 调查已单列“网吧”为上网地点；
- 2000—2002 年多份机构材料显示公共商业上网成为重要接入渠道；
- 2002 年网吧已经形成明确的营业、身份登记与年龄管理制度环境；
- 英国 1994—1999 同样出现从小型 cybercafe 到数百终端公共接入场所的发展。

### 可以合理推断

- 公共上网降低了“必须拥有家庭电脑+电话线”的资产门槛；
- 共享终端会提高服务器端账号相对于本地文件的重要性；
- 网吧终端配置可能影响门户、聊天软件、游戏和浏览器的实际采用路径。

### 尚未知

- 1996—2003 典型城市网吧逐年的浏览器、输入法和软件镜像配置；
- 是否普遍使用系统还原/清理工具，以及具体开始时间；
- 软盘、刻录盘、U盘在公共终端间的数据携带路径；
- 具体网页流量中有多少来自家庭、学校、单位或网吧；
- 不同阶层、性别、流动人口和学生的网吧使用差异；
- 网吧管理员默认首页/桌面快捷方式对早期门户与软件传播的量化影响。

这些缺口适合与 `how-people-lived` 的公共接入生活史专题继续交叉推进。
