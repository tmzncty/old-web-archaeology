# Distance-Education Portals, Courseware, Forums, Enrollment, and Completion-State Gaps, 1999–2008

> Scope: 约 1999–2008 年中文互联网中的现代远程教育/网络教育招生页、网上报名、学习中心、课件入口、论坛/即时通信辅助与完成状态。研究对象不是“中国成人教育史”，也不是今天的 MOOC，而是一个旧网执行问题：**当历史页面写着“网上报名”“进入课程”“在线辅导”时，它究竟证明到哪一个状态？一个招生页或课程目录能不能证明某个成年人真正获得了学习资格、访问了课件、完成考试并取得学历？**

普通生活、在职继续教育、学习时间叠加与四种未来时间感另见 `tmzncty/how-people-lived`：

- `topics/distance-continuing-education-second-chance-learning-and-study-time-stacking-china-1960-2025.zh-CN.md`

本文件遵守 `docs/METHOD.md`：institution / program / recruitment page / learner account / learning center / courseware / forum / assessment record / credential / capture / claim 不混写；`exists / advertised / registered / admitted / accessed / studied / passed / graduated` 不互相替代。

---

## 1. 为什么早期网络教育是典型的“公开入口留下，学习执行消失”系统

旧网档案较容易留下：

- 高校网络教育学院介绍页；
- 招生简章；
- 专业列表；
- 网上报名入口；
- 学习中心地址；
- 教学模式说明；
- 课程目录；
- 公开课件样例；
- 新闻稿；
- FAQ / 帮助页。

一个真实学习者经历的却可能是：

```text
知道某项目
→ 判断学历/工作经验等资格
→ 网上/电话/传真咨询
→ 填报名信息
→ 到地方学习中心提交材料
→ 入学考试或资格审核
→ 获得录取
→ 学号/学生证/账号建立
→ 获得教材与课程权限
→ 在历史网络/客户端中访问课件
→ 下载/观看/阅读
→ BBS/QQ/邮件/在线辅导
→ 面授/学习中心支持
→ 作业
→ 考试/身份核验
→ 学分记录
→ 达到毕业要求
→ 学历/证书注册
→ 在工作中产生或不产生后续结果
```

公共 Web 只覆盖其中一部分。

因此必须固定：

```text
program page exists != authorized learner access
online registration != admission
admitted != courseware successfully reached
courseware listed != historical media survived
resource downloaded != studied
forum activity != course completion
course completion != exam pass
credit earned != graduation
credential page != credential actually issued
```

## 2. 前史边界：远程学习远早于中文大众 Web，本文件不把仓库 scope 无限前移

中国广播电视大学、自学考试等远程/成人教育路线早于互联网几十年。它们对理解 1999 年以后网络教育很重要，因为后来的系统不是从零发明“异地学习”，而是在已有的广播、电视、邮寄教材、电话、教学点和统一考试上增加计算机网络。

本仓仍保持约 1995–2015 中文旧网 scope，因此 1960s–1980s 只作为必要前史，不在这里做广播电视大学通史。

相关机构历史入口：

- 教育部，1960 北京电视大学历史回顾：<https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/s3581/moe_2669/moe_2922/tnull_51117.html>
- 教育部，电大历史回顾：<https://www.moe.gov.cn/jyb_xwfb/s5147/201208/t20120801_140113.html>

Grade: **B/C**（后来的机构历史整理，仅用于前史边界）。

必须固定：

> `distance education existed before Internet != early Web merely copied old media unchanged`

网络后来改变了报名、课件分发、异步问答与跨地域同学关系，但学习中心、线下考试和纸质材料仍长期共存。

## 3. E1 — 1999：现代远程教育试点首先证明制度授权，不证明家庭端已经可执行

教育部同期政策材料显示，1999 年起批准清华大学、浙江大学等高校开展现代远程教育试点，并建立现代远程教育资源建设协调机制；2002 年继续扩大试点高校。

Sources:

- 教育部，现代远程教育试点政策：<https://www.moe.gov.cn/moe_879/moe_207/moe_235/moe_327/tnull_3642.html>
- 教育部，1999-09-15 资源建设通知：<https://www.moe.gov.cn/moe_879/moe_207/moe_235/moe_327/tnull_3608.html>
- 教育部，2002 新增试点高校：<https://www.moe.gov.cn/jyb_xxgk/gk_gbgg/moe_0/moe_8/moe_23/tnull_218.html>

Grade: **A**。

Supported:

- 国家层面明确授权高校探索基于计算机网络的现代远程教育；
- 网络教学、资源建设和管理在制度上已经成为正式研究/办学对象。

NOT supported:

- 1999 年普通家庭已普遍有可用宽带；
- 每名远程学习者在家通过浏览器完成全部流程；
- 某一试点学校的历史课件今天仍可执行；
- 某个报名者最终获得录取或学历。

必须固定：

> `institutional authorization != learner-side executability`

## 4. E2 — 2002：学习中心证明“网络教育”不是纯浏览器系统

教育部 2002–2003 教育信息化发展概况称，截至 2002 年底已有 66 所现代远程教育试点高校和中央电大，累计注册学生超过 150 万，其中 90% 以上是在职人员；全国有 2027 个校外现代远程教育学习中心。

Source:

- 教育部，2003，“2002-2003教育信息化发展概况”：<https://www.moe.gov.cn/srcsite/A16/s7062/200308/t20030812_82372.html>

Grade: **A/B**（官方年度概况）。

这组数字不能用来直接计算 dropout rate；累计注册与当时毕业人数属于不同入学批次和学制阶段。

它能支持更重要的技术结构：

```text
central university/service
+ public telecom/network
+ local learning center
+ learner account
+ printed materials
+ remote courseware
+ face-to-face / synchronous support
+ assessment
```

因此在 archive 中看到一个招生网站时，应同时问：

- 对应学习中心在哪里？
- 哪些动作必须在线下完成？
- 当地机器和网络条件是什么？
- 学习者是家庭上网、单位上网、网吧，还是学习中心终端？

新增：**learning-center handoff gap**。

## 5. E3 — 北外网院标注 2001 年的官方旧文本：历史文字仍在，页面壳却不是历史 capture

北京外国语大学网络教育学院今天仍能访问到标注 2001 年日期的官方内容。

其中一页办学说明写到：

- 学习者可通过网站咨询；
- 也可使用电话/传真；
- 再到当地学习中心办理报名；
- 需经过入学考试/资格流程；
- 教学包含远程学习，也有规律面授与实时在线辅导；
- 学习年限有上限。

Source:

- 北外网院，页面正文标注 2001-07-10：<https://www.beiwaionline.com/aboutbeiwai/news/webinfo/2001/07/1272264154054222.htm>

另一页标注 2001-09-01 的开学报道记录，北京首批数百名学生参加开学活动；学生取得学生证、教材和学习支持手册，全国首批录取约千余人，并依托多个学习中心。

Source:

- 北外网院，页面正文标注 2001-09-01：<https://www.beiwaionline.com/aboutbeiwai/news/webinfo/2001/09/1272264154042488.htm>

Grade: **A/B boundary**。

### 5.1 这类证据能证明什么

- 当前官方站点保存了一段明确标注早期日期的机构文本；
- 文本本身可支持当时宣传/说明中的 hybrid workflow；
- 电话、传真、网站和地方学习中心被同一机构并列使用。

### 5.2 这类证据不能证明什么

本轮没有拿到：

- 2001 年原始 HTML；
- 2001 年的 Wayback/WARC capture；
- 当年 CSS / navigation / sidebar；
- 当年 charset；
- 当年 browser requirement；
- learner login；
- courseware runtime；
- server-side enrollment state。

今天页面中的现代导航、社交入口、CSS 和 CMS 元数据**不得倒写成 2001 年界面**。

新增：**dated-content / current-shell gap（历史正文—现代页面壳错位）**。

这和普通 Wayback capture 不同：

> 页面正文可能很老，但当前 HTTP response 和页面框架是现代系统重新呈现的。

所以应把：

```text
historical textual record
```

与：

```text
historical web artifact
```

分开。

## 6. E4 — 一个 2002 活动在当前 CMS 中显示 2004 发布：内容日期与页面元数据可能分裂

北外网院当前还保留一页关于 2002 年春季招生咨询活动的文本。正文描述的活动发生在 2001 年 12 月至 2002 年 1 月，并记录多城市现场咨询、教学模式演示以及大量网上报名；但当前页面的 CMS “发布时间”字段显示为 2004 年。

Source:

- 北外网院：<https://www.beiwaionline.com/aboutbeiwai/news/webinfo/2004/10/1272264154030103.htm>

Grade: **B / metadata-ambiguous**。

这个案例不适合拿来给 2002 年网页 UI 做精确断代，却非常适合建立一个新的 archive warning：

### content-date / CMS-publish-date ambiguity

```text
正文记述的事件时间
!= 原文首次在线发布时间
!= 后来迁移到 CMS 的发布时间字段
!= 今天访问到的 HTTP 页面生成时间
```

因此：

> `URL path contains 2004 != event happened in 2004`

同时也不能反过来仅凭正文写“2002-01-06”就断言这个 exact URL 在 2002 年已存在。

这是中文站点迁移、CMS 重建和旧内容再发布中非常常见、而且容易被搜索引擎误导的断代问题。

## 7. E5 — 2001–2002 的报名流程：Web 只是 hybrid recruitment stack 的一层

北外网院材料把：

```text
website
+ phone
+ fax
+ local learning-center consultation
+ physical demonstration
```

放在同一招生支持体系里。

这意味着：

```text
online registration
!= online-only recruitment
!= online admission
```

一个用户可能：

1. 在网页上发现项目；
2. 电话咨询；
3. 让朋友代去现场咨询；
4. 到本地学习中心提交资料；
5. 再进入考试/资格审核；
6. 最后才获得账号和课程权限。

公开 Web archive 通常只保留第 1 层或第 2 层之前的信息。

新增：**cross-channel enrollment gap**。

## 8. E6 — 2008 上海电大个案：BBS、QQ 和下载资料已经进入真实学习，但不等于完成状态可见

2008 年《文汇报》同期报道徐胤哲已有法学本科和硕士学历，工作后因建筑工程业务需要，进入上海电视大学建筑工程相关专科学习。

报道记录他的具体学习动作：

- 使用学校/学习群体的 BBS；
- 使用 QQ 群与同学交流；
- 下载成绩较好同学的课堂笔记；
- 把文件保存到硬盘；
- 在有空时自己学习；
- 把所学内容用于工作。

Source:

- 文汇报 / 中国教育在线上海，2008-10-17：<https://shanghai.eol.cn/shanghainews/200810/t20081017_333414.shtml>

Grade: **B**（同期媒体采访）。

这是少见的从“平台存在”推进到“实际用户做了什么”的证据。

但它仍然没有给我们：

- BBS 原线程；
- QQ 历史消息；
- 下载文件的原 URL/hash；
- 当时登录账号；
- 当学期完整课件清单；
- 作业/考试记录；
- 最终学分/毕业结果。

因此必须固定：

```text
reported BBS/QQ use != surviving BBS/QQ artifact
notes downloaded != notes studied
knowledge applied at work != formal credit completed
```

新增：**cross-service learning handoff gap** 与 **study-to-credit gap**。

同时它解释了一类旧网保存偏差：

> 真正的学习过程往往跨 Web、BBS、QQ、本地硬盘、纸质教材和线下课堂，任何一个 archive 都只能留下切片。

## 9. 最小 execution state machine

以后遇到“2003 年某网络大学可以网上报名和在线学习”的 claim，至少尝试拆成：

```text
D0 institution/program legally exists
D1 public recruitment/info page exists
D2 learner discovers program
D3 learner interprets eligibility
D4 web/phone/fax inquiry occurs
D5 online registration data are submitted
D6 institution/backend receives record
D7 local learning center receives/validates materials if required
D8 entrance exam / qualification review occurs
D9 admission decision is issued
D10 student ID/account is created
D11 course/material entitlement is granted
D12 historical client/network can reach resource
D13 learner actually opens/downloads/watches/reads
D14 asynchronous support (BBS/email/QQ) or synchronous tutoring occurs
D15 local face-to-face support occurs where required
D16 assignments are submitted
D17 examination/identity verification occurs
D18 result/credit is posted
D19 cumulative graduation requirements are met
D20 credential is issued / electronically registered
D21 learner uses or does not use credential/skill in later life
```

Hard boundaries:

```text
D1 != D5
D5 != D9
D9 != D13
D13 != D18
D18 != D20
D20 != D21
```

## 10. 需要新增的 archive-gap 类别

### 10.1 dated-content / current-shell gap

老正文被现代 CMS 重新包裹；今天的页面结构不能冒充历史页面结构。

### 10.2 content-date / publish-metadata gap

正文事件日期、首次发布日、CMS 迁移发布时间和当前页面生成时间可能不同。

### 10.3 enrollment-backend gap

公开报名页存在，不代表后台收到、审核或录取。

### 10.4 account-entitlement gap

学生账号、课程权限、付费/学籍资格属于私人动态状态，通常不会进入公共 archive。

### 10.5 courseware-resource gap

课程目录可能保存，但真实视频、音频、课件、压缩包、流媒体地址、授权 token 已丢失。

### 10.6 historical-runtime gap

早期课件可能依赖当时播放器、协议、脚本、带宽和局域网条件；没有实测时不要猜 IE/Flash/RealPlayer 等具体依赖。

### 10.7 learning-center handoff gap

在线流程可能在地方学习中心处转为纸质材料、证件、面授或考试；纯 Web archive 看不到这部分。

### 10.8 cross-service handoff gap

BBS、QQ、email 与网站之间的学习动作跨平台，任何单一 archive 都无法形成完整会话史。

### 10.9 active-vs-registered gap

注册学籍或账号存在，不等于某一时间段真实活跃学习。

### 10.10 assessment/credit gap

公开课件可以看到，但作业、考试、成绩和学分属于私人后台状态。

### 10.11 completion/credential gap

“学校有这一项目”不能推出某个学生毕业；即使毕业，公开 Web 也通常不应恢复个人学历记录。

### 10.12 student-time gap

archive 不会自动保存学习者是否有下班后的两小时、是否因加班/照护暂停、是否把下载的文件真正打开。

## 11. 浏览器、编码与媒体：本轮明确不做过度复原

本轮**没有**取得一个可以可靠验证的 1999–2003 学生登录/课件环境的原始 WARC 或磁盘镜像。

因此本文件不宣称：

- 某站一定要求 IE5/IE6；
- 某页面一定是 GB2312/GBK；
- 某课件一定依赖 Flash、RealPlayer、Windows Media 或 Java；
- 某学习中心一定运行某版本 Windows；
- 某个今天失效的链接当年一定可用。

如果未来拿到历史 capture/安装说明/截图，应分别记录：

- browser/version；
- charset；
- plugin/media runtime；
- viewport；
- network/bandwidth assumption；
- authentication requirement；
- archive rewrite effect。

在那之前，“无法可靠复原当时学生端运行环境”就是正式结论。

## 12. 统计数字的证据边界：registered 绝不能替代 active / completed

2002 年官方概况中的累计注册规模很大，但研究旧网时最危险的误写之一是：

```text
150 万注册
→ 150 万人在某一天使用网站
→ 150 万人完成课程
→ 150 万人取得学历
```

这四个命题完全不同。

一个成熟的数据模型至少需要分别保留：

- cumulative_registered；
- current_enrolled；
- active_in_period；
- completed_courses；
- passed_assessments；
- graduated；
- credential_registered。

如果来源只给一个口径，就不要替它补其他状态。

## 13. 制度真伪与学校/学习中心权限也是网页解释的一部分

教育部后来的政策答疑明确提醒，现代远程学历教育只能由获批准的高校按规定开展，地方学习中心主要承担支持服务，并不因此独立拥有学历授予资格。

Source:

- 教育部，2005，现代远程教育答疑：<https://www.moe.gov.cn/moe_879/moe_1252/s6035/s6038/s2992/moe_1268/tnull_17508.html>

Grade: **A**（同期/近同期官方制度说明）。

因此一个历史广告页说“某学习中心招生”时，应继续问：

```text
who is the degree-granting institution?
is this learning center authorized?
what program/batch was approved?
what exactly is being promised?
```

新增：**institution-role ambiguity**。

旧网里品牌、地方中心、中介、广告站和正式高校页面可能相互链接或复用名称，不能把它们合并成一个主体。

## 14. 隐私与版权边界

远程教育 archive 很容易诱使研究者去寻找：

- 历史学生账号；
- 姓名、身份证号；
- 电话/email；
- 成绩；
- 作业；
- QQ 号；
- 论坛私信；
- 学籍/学历记录。

这些不是为了证明平台结构所必需的公开对象。

本仓继续按“研究必要最小化”处理：

- 优先保存公开招生页、帮助页、课程说明与机构文档；
- 普通学习者只在同期公开报道已经匿名化/公开且对 claim 必要时引用；
- 不恢复私人账号；
- 不测试历史登录凭据；
- 不重新发布历史成绩和身份信息；
- 课件版权不明时只记录 locator/metadata/分析，不复制整套资源。

因此：

> **learner-state invisibility 很多时候不是 archive failure，而是合理的 privacy boundary。**

## 15. 反例与后见之明检查

### 反例 1：网络教育出现不等于广播/教材/学习中心消失

早期系统本身就是 hybrid stack。不能用今天全移动端课程的体验倒写 2001。

### 反例 2：网页更多不等于学习更容易完成

在职学习者仍受工作时间、家庭责任、考试、学费与线下实践约束。

### 反例 3：current official page 不等于 historical capture

一个高校今天仍保留 2001 年文字，非常有价值，但它只能作为“历史正文被当前官方系统保存”的证据；除非拿到 capture，否则不能用今天 DOM/CSS/导航复原 2001 页面。

### 反例 4：媒体里的高参与学习者存在 selection bias

愿意接受采访、能讲出 BBS/QQ/工作应用细节的人，更可能是持续学习者。不能由此估计全体学生的活跃度。

### 后见之明风险

不要把 1999 网络教育写成今天 MOOC 的“不成熟版本”。当时把高校、公共电信网、地方学习中心、纸质教材、面授与网络结合，是对当时带宽、终端所有权、数字技能和资格认证条件的工程响应。

## 16. 本轮负结果

本轮没有可靠恢复：

- 1999–2003 某试点高校普通学生端完整登录 capture；
- 同一学生从报名到毕业的公开、可验证多时点 Web 执行链；
- 早期北外网院学生区/课件区的 verified historical HTML/WARC；
- 2008 个案所用 BBS 原线程和 QQ 历史会话；
- 可以合法公开的个人作业—考试—学分—毕业完整链。

因此本文件只建立 evidence contract 和已能核验的混合流程，不宣称完成某一历史学习平台的 UI/runtime reconstruction。

---

## 17. 它对中文旧网考古增加了什么

远程教育门户说明，中文旧网中存在一大类不能把“页面”当作研究终点的 **process Web**：

```text
public recruitment shell
→ private enrollment backend
→ offline identity/learning-center handoff
→ private learner account
→ partially public courseware
→ cross-service communication
→ private assessment state
→ offline/official credential
```

它和招聘、订票、医院预约、网银等案例共享一个核心规律：

> **旧网页最容易保存“可以开始做什么”，最难保存“某个普通人最后到底做成没有”。**

而本专题又多出两个独特问题：

1. **时间执行不可见**：archive 看不到一个在职学习者是否真的在夜晚打开了下载文件；
2. **多媒介执行不可见**：真正的课程同时发生在 Web、BBS、QQ、硬盘、纸教材、地方学习中心和考场。

因此远程教育考古的目标不应该是强行拼出一个“完整在线校园”，而是准确画出：

> 哪些状态曾经公开可见，哪些状态由私人后台、线下机构和普通人的碎片时间共同完成，以及今天为什么只剩入口而不是完整人生结果。
