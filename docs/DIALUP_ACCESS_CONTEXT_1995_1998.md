# 1995—1998 拨号接入背景：早期中文网页存在，不等于普通人容易看见

本文件补充 `docs/PREHISTORY_BOUNDARY.md`，服务于一个非常具体的旧网考古问题：

> **当我们在档案里看到 1995—1998 年的中文网页、BBS 或服务页面时，当时究竟哪些人现实中有条件访问它？**

主研究期仍然是约 1995—2015 年中文互联网；本文不扩张为完整电信史，而是给最早几年网页和社区案例补上必要的接入背景。

---

## 1. 早期旧网页需要两条证据链

一个 archive capture 可以证明：

- 某 URL 在某时点可能存在；
- 页面当时包含某些文字、链接、图片或脚本；
- 某服务宣称提供某些功能。

但它**不能单独证明**：

- 普通家庭当时容易访问；
- 全国用户都处于同一种网络环境；
- 某网站已经“大众流行”；
- 一个现代浏览器能打开的 capture，当年在家庭拨号条件下也有相同体验。

因此 1995—1998 案例至少要同时维护：

1. **page/platform evidence**：页面、服务、平台本身的历史证据；
2. **access-environment evidence**：电话线、拨号、机构网络、电脑、接入服务、费用和用户规模的证据。

这两个层级必须分开。

---

## 2. 电话基础设施本身仍在快速扩张

国家统计局历史序列中的“电话普及率（包括移动电话）”单位为**部/百人**：

| 年份 | 电话普及率（部/百人） |
|---|---:|
| 1994 | 3.20 |
| 1995 | 4.66 |
| 1996 | 6.34 |
| 1997 | 8.11 |
| 1998 | 9.95 |

来源：

- 国家统计局，《中国统计年鉴 2011》，表 16-39“电信通信服务水平”：<https://www.stats.gov.cn/sj/ndsj/2011/html/P1639C.HTM>

这里绝不能把“4.66 部/百人”改写成“4.66% 家庭有电话”。

该指标只能说明电话终端相对于人口的密度。

它对旧网考古的重要意义是：

> **1995 年的家庭拨号 Internet 建立在一个仍远未达到今天“家家有线路、人人有终端”状态的电话环境上。**

所以同一年里，一个高校实验室、城市单位办公室和普通家庭的 Internet 可及性可能完全不同。

---

## 3. 1997：早期社会 Internet 已出现，但拨号是绝对主力

CNNIC 第一次全国互联网调查以 1997 年 10 月 31 日为截止日，记录：

- 上网计算机 **29.9 万台**；
- 其中直接上网计算机 **4.9 万台**；
- 拨号上网计算机 **25 万台**；
- 上网用户 **62 万人**；
- 大部分用户通过拨号方式上网。

来源：

- CNNIC，《第一次中国互联网络发展状况调查统计报告》：<https://www3.cnnic.cn/n4/2022/0401/c88-802.html>

因此研究 1997 年网页时，默认“用户坐在宽带电脑前”是严重的时代错位。

一个典型拨号用户需要的不是单独一项“Internet 服务”，而是一整套栈：

```text
可用电脑
+ modem
+ 电话线路
+ Internet 接入帐号/服务
+ 电话与接入资费
+ 可以占用线路的一段时间
+ 能完成拨号和网络配置的知识
```

只缺一层，家庭 Internet 就可能不可用。

---

## 4. 1998：用户快速增长，但“拨号生态”仍然非常清楚

CNNIC 第二次调查以 1998 年 6 月 30 日为截止日，记录：

- 上网计算机 **54.2 万台**；
- 其中直接上网 **8.2 万台**；
- 拨号上网 **46 万台**；
- 上网用户 **117.5 万人**；
- 其中直接上网用户约 32.5 万，拨号用户约 85 万。

来源：

- CNNIC，《第二次中国互联网络发展状况调查统计报告》：<https://www.cnnic.net.cn/n4/2022/0401/c88-780.html>

从 1997 年到 1998 年，用户规模增长很快。

但“增长很快”不等于“已经普及”。

对于 1998 年的网站，最稳妥的描述仍然是：

> Internet 已经进入公共社会生活，但用户仍是高度选择性的少数群体，而且拨号接入占据主要位置。

## 5. 1998 年电话、寻呼、公用电话和 Internet 是并存系统

国家统计局 1999 年发布的新中国 50 年邮电通信分析，对 1998 年记录：

- 全国公用电话网拥有电话用户近 **9000 万户**；
- 城市居民家庭 **70% 以上**安装住宅电话；
- 移动电话用户 **2386 万**；
- 无线寻呼用户 **3908 万**；
- 公用电话 **259 万部**；
- 已通电话行政村占 **67.1%**；
- 农村邮件平均每周投递 **4.3 次**。

来源：

- 国家统计局，《邮电通信业突飞猛进——新中国50年系列分析报告之十一》，1999：<https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920449.html>

这组数字对旧网页解释很重要，因为它说明 1998 不能被写成“旧通信方式已经被 Internet 取代”。

同一个城市用户可能：

- 用住宅电话或单位电话通话；
- 带 BP 机接收通知；
- 在外面用公用电话回拨；
- 偶尔在单位、学校、家庭或公共上网场所接触 Internet；
- 继续用报纸、邮件和实体人才市场获得信息。

**旧网是叠加在既有通信系统之上的，而不是一天把它们清空。**

---

## 6. 寻呼机和公用电话不能被误写成“另一种上网方式”

寻呼和公用电话属于早期中文 Internet 的社会环境，但它们不是 Internet 接入本身。

无线寻呼解决的是“人离开固定电话后仍能知道有人找他”的问题；公用电话提供的是城市中的语音回复端点。

它们可以影响：

- 网站上联系方式的写法；
- 早期个人主页/商业页面是否留下 BP 机号码；
- 网友约线下见面的协调方式；
- 网络信息怎样被转回电话或现实会面。

但不能因为一个人有 BP 机，就推断这个人也有电脑、modem 或 Internet 帐号。

以后遇到 1990 年代页面上的联系方式时，应把：

```text
固定电话
BP / pager
传真
电子邮件
ICQ/OICQ 等账号
邮政地址
```

分别记录，而不是统一抽象成“联系方式”。

这些字段本身就是时代结构。

## 7. “直接上网”与“拨号上网”对应的是不同生活环境

CNNIC 报告区分直接上网与拨号上网，本仓以后也应保留这种区别。

### 直接/机构网络路径

更可能出现在：

- 高校；
- 科研机构；
- 网络建设单位；
- 部分企业和机关；
- 专线或校园网络环境。

这类用户可能不需要每次拿普通住宅电话线路拨号。

### 家庭/个人拨号路径

通常要求：

- 家里或可控制地点有电话线；
- 一台可联网电脑；
- modem；
- 拨号接入服务；
- 承担通信费用；
- 接受占线。

因此“1997 年有人可以在宿舍或实验室一直在线”与“1997 年普通家庭都能以同样方式上网”之间不存在自动推导关系。

旧网案例应该尽量记录其典型用户更接近哪一种路径。

## 8. 早期网页的用户偏差不是噪声，而是历史事实

如果 1996—1998 年留下网页的人更可能来自：

- 高校；
- 科研技术群体；
- 城市单位；
- 有电脑和电话条件的家庭；
- 互联网行业和电脑爱好者群体；

那么今天 archive 中“被保存下来的普通人”本身就是被接入条件筛选过的一群人。

这会产生一种双重选择：

1. **谁当时有条件留下网页；**
2. **谁的网页后来又被 archive 保存。**

所以不能把 1990 年代个人主页的审美、职业、兴趣、教育程度或城市经验直接扩展为当时全体人口文化。

这不是说个人主页不适合做人类生活史。

恰恰相反，它非常珍贵，但必须明确：

> **这是“早期在线人口”的生活史，不是未经校正的全国人口切片。**

## 9. 一个海外对照提醒：modem 的意义依赖此前的电话网

`tmzncty/how-people-lived/topics/reachability-before-personal-internet-1980-1998.zh-CN.md` 比较了美国 BBS 环境。

美国人口普查局住房历史表显示，1980 年约 7% 的住房没有电话，也就是约 93% 已有电话。

来源：

- U.S. Census Bureau, *Historical Census of Housing Tables: Telephones*: <https://www.census.gov/data/tables/time-series/dec/coh-phone.html>

Computer History Museum 对 BBS 的回顾指出，1980—1990 年代 BBS 使用依赖个人电脑、modem 和电话网络，本地电话资费结构还会塑造社区的地理范围。

来源：

- Computer History Museum, “Dialing Up Community: The Legacy of Bulletin Board Systems”: <https://computerhistory.org/blog/dialing-up-community/>

这个对照在本仓只承担一个方法提醒：

> **modem 是同一种设备，但在不同电话普及率和资费制度下，它不会自动产生同样规模、同样地理结构的网络社区。**

本仓不在此扩写美国 BBS 史。

## 10. 对 1995—1998 旧网案例建议增加的 access 字段

在 `docs/PREHISTORY_BOUNDARY.md` 已有字段基础上，建议早期案例额外考虑：

| 字段 | 需要问什么 |
|---|---|
| access_mode | direct / campus / leased-line / dial-up / public-access / unknown |
| telephone_dependency | 是否依赖普通电话线 |
| modem_dependency | 是否需要用户自备 modem |
| access_location | 家庭 / 单位 / 学校 / 网吧或机房 / 未知 |
| line_occupancy | 使用时是否会占用普通电话线 |
| tariff_evidence | 是否找到电话费 / 接入费 / 套餐证据 |
| user_scale_evidence | 是否有同时代用户规模证据 |
| population_bias | 哪些人更可能有条件访问 |
| offline_bridge | 页面信息是否需要电话 / BP机 / 传真 / 线下会面继续完成 |

这些字段不是每个案例都必须填满。

但缺失时应写 `unknown`，不要让现代经验自动补进去。

## 11. 对页面内容解释的几个直接后果

### 联系方式是一手社会史料

一个 1997 年网页同时列：

- 邮政地址；
- 固定电话；
- BP 机；
- 传真；
- Email；

它证明的不只是“作者留下了五种联系方式”。

它还显示：在线身份仍然必须与多个线下/电信系统协同工作。

### “请发邮件”不等于对方持续在线

拨号生态里，Email 可以是异步的；用户可能只在特定时段上线收信。

除非有在线时长或使用习惯证据，不要默认为今天手机推送式的持续可达。

### 网页加载时间也是历史体验的一部分

早期家庭拨号意味着图片数量、文件尺寸、Flash/Java 等插件资源不只是视觉问题，也可能影响等待时间和费用。

以后浏览环境实验除了 IE/Netscape/CSS/编码，还应尽可能考虑：

- modem 速率假设；
- 页面总资源大小；
- 失败子资源；
- 是否必须反复拨号；
- 电话线路是否同时承担家庭语音通信。

这属于 M3 浏览环境复原可以继续发展的方向。

## 12. 已证实 / 高概率 / 不知道

### 已证实

- 1994—1998 中国电话密度持续快速上升，但仍处于明显扩张期；
- 1997、1998 CNNIC 的早期 Internet 用户中，拨号路径占据主要位置；
- 1998 年电话、寻呼、公用电话、移动电话、邮政与早期 Internet 明显并存；
- Internet 的早期社会用户规模远小于后来大众化阶段。

### 高概率，但每个具体案例仍需证据

- 1995—1998 的中文个人网页和社区用户比全国人口显著更城市化、技术化、教育机构化；
- 很多早期 Web 信息需要电话、邮件、传真或线下会面完成后续动作；
- 家庭拨号成本和占线会显著影响使用时段与浏览行为。

### 仍不知道 / 需要继续研究

- 1995—1998 主要 ISP 的真实家庭接入资费与电话费叠加方式；
- 28.8k / 33.6k / 56k modem 在中国不同年份的实际普及比例；
- 早期网吧、电脑房怎样绕过“必须自己有电脑 + 电话线”的门槛；
- 城市、县城、农村之间 Internet 公共接入差距；
- 不同高校宿舍和校园网条件；
- 页面资源大小在当时典型链路下的真实加载时间。

## 13. 核心方法结论

对于 1995—1998 中文旧网，至少同时保留三句话：

```text
这个网页存在。
某些人有办法访问。
普通人是否容易访问，需要另一组证据。
```

这三句话不能互相替代。

旧网页考古如果只保存第一句，就会把技术存在误写成社会普及；如果只研究用户规模，又会失去页面本身的历史细节。

本仓真正需要的是把两条证据链重新接起来：

> **页面当时是什么样 + 一个当时的人需要什么条件才能真的看到它。**
